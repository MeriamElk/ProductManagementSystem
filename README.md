# Product Management System

Mini projet de stage visant à développer une application de gestion de produits avec
un **backend FastAPI (GraphQL)** et un **frontend Angular**.

L’objectif est de mettre en place une architecture claire, maintenable et évolutive,
séparant correctement le frontend et le backend.

---

## 📌 Objectifs du projet

- Gérer des produits (CRUD)
- Mettre en place une API backend avec FastAPI et GraphQL
- Développer une interface utilisateur avec Angular
- Appliquer de bonnes pratiques de structuration et de versioning Git
